# Sources des images de référence

Usage : **références de travail internes** pour la direction artistique et la modélisation ; aucune image n'est
utilisée comme texture, ni publiée, ni versionnée dans le dépôt. Les licences libres de Wikimedia Commons exigent
l'attribution (auteur, licence) et, pour CC BY-SA, le partage dans les mêmes conditions de toute œuvre **dérivée de
l'image** : les modèles 3D sont des créations originales inspirées des véhicules, pas des dérivés des photographies.

## 1. Méthode

- Date de consultation : 2026-11-04 (indiquée pour chaque image dans les manifestes).
- Source : API de Wikimedia Commons (catégories du modèle et sous-catégories de premier niveau ; sous-catégories de
  compétition, police, préparation, concept et maquette exclues), licences libres seulement (CC BY, CC BY-SA, CC0,
  domaine public), largeur ≥ 1 200 px.
- Téléchargement : vignettes de 1 280 px (lien vers l'original conservé) dans `E:/ROBLOX DEV/aw-vehicle-references/`.
- Angle : proposé d'après le titre, puis **vérifié à l'œil** sur planche contact ; images non conformes écartées avec
  leur raison.
- Outils : scripts de travail locaux (requêtes par `curl`, vérification TLS normale) ; non versionnés.
