8. Accessibilité

ContrasteTexte ≥ 4,5:1 partout. Contraste renforcé : bordures #6B6F77, texte secondaire #D9D7D2, aucun texte sous 0,45 d'opacité hors désactivés.
Taille du texteAccess.TextScale 80–150 % appliqué via UIScale sur les TextLabel ; les cadres s'allongent (AutomaticSize Y) au lieu de couper.
Textes anglaisPrévoir +35 % de longueur. Onglets à largeur automatique, défilement horizontal sans barre, aucun texte tronqué sur une action.
ManetteFocus visible (contour ambre 2 px). Sélection imposée seulement si le dernier périphérique est la manette (correctif du lot 0.8). Aucune sélection en mode rapide.
